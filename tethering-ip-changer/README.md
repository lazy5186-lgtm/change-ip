# 모바일 테더링 IP 변경기

갤럭시/아이폰 USB 테더링을 통해 IP를 변경하는 도구입니다.

## 기능

- 📱 테더링 인터페이스 자동 감지 (SAMSUNG, Android, iPhone)
- 🔄 원클릭 IP 변경
- ⏱️ 대기 시간 커스터마이징
- 📊 실시간 로그 표시

## EXE 빌드 방법

### 1. 사전 요구사항

- Node.js 설치 (https://nodejs.org)
- Windows 환경

### 2. 의존성 설치

```bash
cd tethering-ip-changer
npm install
```

### 3. 빌드

```bash
# Portable EXE (단일 실행 파일)
npm run build

# 설치 파일 (NSIS 인스톨러)
npm run build-installer
```

### 4. 빌드 결과

빌드가 완료되면 `dist` 폴더에 `IP변경기.exe` 파일이 생성됩니다.

## 사용 방법

1. **관리자 권한으로 실행** (필수!)
   - `IP변경기.exe`를 우클릭
   - "관리자 권한으로 실행" 선택

2. 프로그램이 자동으로 테더링 인터페이스를 감지합니다.

3. 필요시 대기 시간을 조절합니다:
   - 비활성화 대기: 3초 권장
   - 재연결 대기: 8~10초 권장 (연결이 불안정하면 늘리세요)

4. "IP 변경하기" 버튼 클릭

## 문제 해결

### "관리자 권한이 필요합니다" 오류
- 반드시 관리자 권한으로 실행해야 합니다.

### 테더링 인터페이스를 찾을 수 없음
- USB 테더링이 켜져 있는지 확인
- USB 케이블이 데이터 전송을 지원하는지 확인
- 드라이버가 설치되어 있는지 장치 관리자에서 확인

### IP가 변경되지 않음
- 재연결 대기 시간을 늘려보세요 (10~15초)
- 네트워크 연결이 완전히 끊어졌다가 다시 연결되어야 IP가 바뀝니다.

## 아이콘 추가 (선택사항)

`icon.ico` 파일을 프로젝트 폴더에 추가하면 EXE 아이콘이 적용됩니다.
256x256 크기의 ICO 파일을 권장합니다.
